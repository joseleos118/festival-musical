
# Festival Musical

Programa desarrollado en Python para simular un festival musical utilizando herencia, polimorfismo y redefinición de métodos.

## Estructura del proyecto

- `main.py`: permite registrar artistas e iniciar el festival.
- `clases/artistas.py`: contiene la clase Artista y las clases Cantante, DJ y Banda.

## Requisitos

- Python 3

## Ejecución

Desde la terminal, entra en la carpeta del proyecto y ejecuta:

```bash
python3 main.py
```

El programa solicita la cantidad de artistas y sus datos. Al terminar el registro, muestra la presentación, actuación y despedida de cada artista.
